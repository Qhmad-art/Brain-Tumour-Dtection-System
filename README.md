# 🧠 Brain Tumor Detection System
# https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset

An AI-powered Brain Tumor Detection System that uses Deep Learning and Transfer Learning to classify brain MRI images and detect potential tumors.

## 🚀 Features
- Brain MRI image classification
- Deep Learning and Transfer Learning
- Image preprocessing and prediction
- Model evaluation using a confusion matrix and classification metrics
- FastAPI integration for model deployment

## 🛠️ Tech Stack
- **Language:** Python
- **Deep Learning:** TensorFlow, Keras
- **Image Processing:** OpenCV, NumPy
- **Visualization:** Matplotlib, Seaborn
- **API:** FastAPI

## 🎯 Objective
To develop an AI-based system that assists in identifying potential brain tumors from MRI images.

## ⚠️ Disclaimer
This project is for educational and research purposes only. It is not a substitute for professional medical diagnosis.
